# RCM v0.8.0 (`rcm-rs`)

- **Crate rename**: published as `rcm-rs` on crates.io (the name `rcm` was already taken by an abandoned placeholder).
- Binary name remains **`rcm`** — install with `cargo install rcm-rs`, then run `rcm`.
- LET remains the prime bonded imperative (`rcm let ...`).
- CI continues to publish on `v*` tags.
